# 03. 入力を常時スプレッドシート／CSVに集める

やりたいこと：**利用者が書いた相談内容を、常にスプレッドシート（またはCSV）に残す。**

方法は2段階あります。**（A）は最初から動いています。**（B）を設定すると「常時・自動」になります。

---

## (A) いますぐ使える：端末に貯めて → CSV書き出し（設定不要）

アプリは相談を送るたびに、その端末の中に記録しています。運営がCSVを取り出すには：

1. アプリを開く
2. 右上の **設定** → **相談ログを書き出す（CSV）**
3. `bosai-soudan-log.csv` がダウンロードされます（Excel / Googleスプレッドシートで開けます）

- 文字コードは BOM付きUTF-8 なので、日本語がExcelでも文字化けしません。
- 列：`送信時刻 / 相談の種類 / 年代設定 / 返しの種類 / 情報量 / 本文`

⚠️ この方式は「その端末で開いたCSV」だけです。**テスターの端末に分散する**ため、全員分を1か所に集めたい場合は (B) を設定してください。

---

## (B) 常時・自動でスプレッドシートに集める（推奨・無料）

GitHub Pages はサーバーを持てないので、**Google Apps Script を“受け口”**にします。アプリは相談のたびに、この受け口へ1件ずつ送信し、スプレッドシートに追記されます。**費用ゼロ・登録不要・クレジットカード不要**です。

### 手順

1. **Google スプレッドシートを新規作成**します（名前は自由。例：`相談ログ`）。
2. スプレッドシートのメニュー **拡張機能 → Apps Script** を開きます。
3. 最初のコードを全部消し、`tools/appscript_sheet_logger.gs` の中身を**丸ごと貼り付け**て保存します。
4. 右上の **デプロイ → 新しいデプロイ** を選びます。
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - **デプロイ** を押すと、`https://script.google.com/macros/s/……/exec` という **ウェブアプリのURL** が出ます。これをコピー。
5. `index.html` を開き、先頭の `CONFIG` の `LOG_ENDPOINT` にそのURLを貼り付けます。

```js
const CONFIG = {
  LOG_ENDPOINT: "https://script.google.com/macros/s/……/exec",  // ← ここに貼る
  QUICK_EXIT_URL: "https://www.google.com/",
  KNOWLEDGE_URL: "./knowledge.json"
};
```

6. `index.html` を保存して GitHub に上げ直せば完了。以降、相談が入るたびにスプレッドシートの `ログ` シートに1行ずつ増えます。感想は `感想` シートに入ります。

### 動作確認

- 手順4のURLをそのままブラウザで開くと `{"ok":true,...}` と出れば受け口は生きています。
- アプリで1件相談を送り、スプレッドシートに行が増えれば成功です。

### よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 行が増えない | デプロイの「アクセスできるユーザー」が**全員**になっているか確認。 |
| コードを直したのに反映されない | Apps Script は **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ** で更新が必要。 |
| URLを変えたのに古い方に届く | 「新しいデプロイ」を作ると **URLが変わります**。新URLを `LOG_ENDPOINT` に入れ直す。 |

---

## プライバシー設計（先に決めておくこと）

繊細な相談を扱うため、**何を残すか**は運営が意図的に選んでください。

- **本文を残さない**：アプリの初回設定／設定メニューでオンにできます。オンのとき、スプレッドシートの「本文」列は**空**で届き、「相談の種類」だけが集計されます。まずはこの状態で内部テストするのが安全です。
- **保存先の共有範囲**：スプレッドシートの共有は運営メンバーだけに限定してください。
- **保管期間**：テスト終了後に不要な行を消す運用を、あらかじめ決めておきます。
- **同意の文言**：テスターへの案内に「相談内容は改善のため運営が匿名で記録します」と一言添えると誠実です。

## Slack に流したい場合（任意）

スプレッドシートの代わりに Slack へ通知したいときは、Slack の **Incoming Webhook URL** を作り、`LOG_ENDPOINT` にそれを入れる…のではなく、Apps Script 側から Slack にも投げる1行を足すのが安全です（キーをアプリ側に置かないため）。必要になったら `appscript_sheet_logger.gs` の `doPost` 末尾に `UrlFetchApp.fetch(SLACK_WEBHOOK, {...})` を1行足してください。
